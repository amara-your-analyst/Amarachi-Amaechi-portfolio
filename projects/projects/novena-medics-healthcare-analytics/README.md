# Novena Medics — Healthcare Data Analytics

## Project Overview

Novena Medics is a healthcare data analytics case study built around a structured patient dataset containing 189 patient records.

The project explores patient demographics, geographic distribution, diagnoses, treatment types, assigned medical personnel, hospital stay duration, treatment costs, and patient outcomes.

The dataset was analysed and presented through an interactive Power BI dashboard to demonstrate how structured healthcare data can be transformed into information that supports operational reporting and decision-making.

The analysis focuses on identifying patterns in patient activity, treatment, cost, length of stay, and outcomes, while demonstrating practical data analysis and visualisation techniques in a healthcare context.
